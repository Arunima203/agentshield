================================================================================
                            SCORING SYSTEM
================================================================================

DETERMINISTIC SCORING (60% weight):
  Base: 10-80 per tool
  + Heuristics: +10 to +50 per finding
  + Secrets: +20 per discovery
  + Domain violations: +60
  Final: min(100, base + findings)

LLM SEMANTIC SCORING (40% weight):
  • Context understanding: 0-40
  • Intent analysis: 0-30
  • Pattern recognition: 0-20
  • Confidence: 0.0-1.0

COMBINED SCORE:
  final = (det_score × 0.60) + (llm_score × 0.40)

DECISION MATRIX:
  0-29:   ALLOW (safe)
  30-59:  REVIEW (medium risk)
  60-84:  REVIEW (high risk)
  85-100: BLOCK (critical)

  LLM_TEMPERATURE=0
  LLM_API_PORT=8000
  LLM_API_HOST=127.0.0.1

CUSTOMIZATION:
  • Score weights: Edit combineScores() in interceptor.ts
  • Thresholds: Edit backend/agentshield.config.yaml
  • Model: Use different Ollama model
  • Disable LLM: ENABLE_LLM=false
